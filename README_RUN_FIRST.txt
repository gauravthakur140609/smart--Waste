ECOGRID — Smart Solid Waste Management using AI + IoT

IMPORTANT: open THIS folder in VS Code (the folder containing package.json).

1) Open a terminal in this folder.
2) Run: npm install
3) Run: npm run dev
4) Open the Local URL shown by Vite (normally http://localhost:5173/)

This version includes:
- Multi-item EcoAI search (plastic, paper, cardboard, glass, metal, organic, e-waste, textile, wood, tyres, drink cartons)
- Synonym/phrase matching for common household waste
- Real-world photo references from Unsplash in the UI
- Recycling Lab with material-specific process traces
- Product Studio with visible manufacturing stages and product images
- IoT City smart-bin monitoring and route-priority simulation

Internet is required for the external photo references. The AI demo itself does not require an API key.
